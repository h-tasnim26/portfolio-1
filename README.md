## Customize before publishing
1. Replace the generic LinkedIn, GitHub, and Facebook links with your actual profile URLs.
2. Add only real completed projects, certificates, experience, and skills. The site intentionally does not claim unprovided qualifications.
3. Update project links and images when your projects are ready.
4. The contact form opens the visitor's email app with a prefilled message. Connect a form backend/service for direct online submissions.

## Deploy
Upload all files and the `assets` folder to GitHub Pages, Netlify, or your web hosting public directory.
